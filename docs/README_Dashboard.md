# Health.Env - Dengue Risk Prediction Dashboard

## 🚀 Quick Start

### HTML Version (Recommended)
Simply open `index.html` in your browser:
- Double-click `index.html`
- Or right-click → Open with → Browser

### Streamlit Version (Alternative)
```powershell
pip install -r requirements.txt
streamlit run app.py
```

## 📁 Files
- `index.html` - Main HTML dashboard (Black & White theme)
- `styles.css` - Modern styling with glassmorphism
- `script.js` - Interactive functionality & charts
- `app.py` - Streamlit version (alternative)
- `requirements.txt` - Python dependencies

## 🎨 Design Features
- ✅ Clean black & white aesthetic
- ✅ High contrast for readability
- ✅ Organized grid layout
- ✅ Interactive sliders & inputs
- ✅ Real-time prediction updates
- ✅ 4 dynamic data visualizations
- ✅ Responsive design
- ✅ Smooth animations

## 🔧 Customization
All colors and styling are in CSS variables in `styles.css`:
- `--bg-primary` - Main background
- `--text-primary` - Primary text color
- `--risk-low/moderate/high` - Risk level colors
